# 09 — Будущее: интеграция генеративного API

Этот документ — проектная заготовка. Реализация — фаза 7 (`07-roadmap.md`). Не писать код сетевых вызовов до фазы 6–7.

## 1. Цель

Дать мастеру и игрокам кнопку «Сгенерировать» прямо в приложении:
- **Картинки**: портреты NPC, арт локаций, иллюстрации событий.
- **Карты**: новые игровые поля для приключения (в стиле `08-assets.md`).
- **Персонажи/NPC**: черновики NPC с именем, расой, классом, кратким описанием.
- **Случайные события**: таблицы/заметки «на лету» во время сессии.

## 2. Подход

- Внешний провайдер с **OpenAPI-спецификацией** (routerai-подобный роутинг: один API-ключ → разные модели).
- Абстракция `GenProvider` в коде: единый интерфейс, конкретные провайдеры — адаптеры.
- Ключ API хранится локально на устройстве пользователя (настройки), не в репозитории.
- Всё сгенерированное — **как homebrew**: помечается источником «AI», не смешивается с официальными данными `data/catalogs/`.

## 3. Точки входа в UI

| Экран | Действие «Сгенерировать» |
|---|---|
| Билдер персонажа | аватар, черновик предыстории |
| Справочники | картинка к записи (не обязательна) |
| Приключение (мастер) | карта-подземелье, NPC, событие, лор-заметка |
| Комната (мастер) | «показать игрокам» — сгенерированную картинку |
| Комната (все) | случайное событие, «что в сундуке?» |

## 4. Архитектурные требования

- Провайдер выбирается в настройках; поддержка минимум 2х провайдеров (основной + запасной).
- Промты — шаблоны с плейсхолдерами (стиль из `08-assets.md`), редактируемые пользователем.
- Кэширование результатов на диске, чтобы не платить дважды.
- Ограничения: таймауты, ретраи, деградация («сервис недоступен» — не ломает игру).

## 5. Безопасность и правовые замечания

- Не отправлять персональные данные пользователей в API.
- Генерированный контент помечается как неофициальный; в UI — индикатор «AI».
- Пользователь несёт ответственность за соответствие лицензии провайдера.

## 6. Что НЕ делать сейчас

- Не встраивать вызовы API в код до фазы 7.
- Не смешивать AI-контент с официальными каталогами.
- Не хранить ключи в коде/репозитории.
