# DNDProd — документация для ИИ-агентов

Этот репозиторий — основа для разработки **десктопного приложения для Windows**, которое с самого начала проектируется для **лёгкого переноса на Android и macOS** без переписывания ядра. Документы написаны так, чтобы **любой ИИ-агент мог собрать приложение по этим правилам**. Правила строго официальные (Player's Handbook 2014 + официальные дополнения), источник истины — сайт [dnd.su](https://dnd.su).

> **Как пользоваться**: начни с `01-architecture.md`, затем читай разделы по мере нужды.
> Все числа и названия здесь сверены с dnd.su; полные данные лежат в `data/catalogs/*.json`.

## Данные (data/catalogs/)

**Все агенты обязаны брать игровые данные из этих JSON, а не выдумывать.**

| Файл | Записей | Что внутри |
|---|---|---|

| `_classes_core.json` | 13 | Классы: кость хитов, хиты, спасброски, навыки, доспехи, список подклассов |
| `_classes_subclass_anchors.json` | 13 | Подклассы с якорями-ссылками на dnd.su |
| `races_5e14.json` | 80 | Расы: название (ru/en), источник, ссылка |
| `_races_subspecies.json` | 68 | Расы: подвиды с якорями |
| `spells_5e14.json` | 524 | Заклинания: уровень, школа, время, дистанция, компоненты, длительность, классы, концентрация, ритуал |
| `bestiary_5e14.json` | 2673 | Монстры: размер/тип, КД, хиты, CR, опыт, навыки, чувства, языки, среда обитания |

## Быстрые ссылки на dnd.su (для агента)

- Классы: `https://dnd.su/class/<id>-<slug>/` — например [Воин](https://dnd.su/class/91-fighter/)
- Расы: `https://dnd.su/race/<id>-<slug>/` — [Эльф](https://dnd.su/race/79-elf/)
- Заклинания: `https://dnd.su/spells/<id>-<slug>/` — [Огненный шар](https://dnd.su/spells/115-fireball/) (см. каталог)
- Бестиарий: `https://dnd.su/bestiary/<id>-<slug>/`
- Предметы: `https://dnd.su/items/<id>-<slug>/`
- Предыстории: `https://dnd.su/backgrounds/<id>-<slug>/`
- Черты: `https://dnd.su/feats/<id>-<slug>/`
- Механики: `https://dnd.su/articles/mechanics/` · Инвентарь: `https://dnd.su/articles/inventory/`

## Железные правила для агентов

1. **Не выдумывай правила.** Все числа, названия, уровни умений — из `data/catalogs/` или по ссылке на dnd.su.
2. **Единый язык — русский** в UI и документации; идентификаторы в коде — английские snake_case.
3. **Официальный контент — приоритет.** Homebrew не добавляем, пока нет явной команды.
4. **Изменения фиксируй в `07-roadmap.md`** — см. правило обновления плана.
5. **Не коммить сгенерированные данные в git**, если они большие, — каталоги уже в `data/`, источник — скрипт.
6. **Кроссплатформенность Windows → Android и macOS**: никакого кода, завязанного только на Windows; платформенное — за интерфейсами в `platform/`. Стек — Flutter, см. `01-architecture.md`.
