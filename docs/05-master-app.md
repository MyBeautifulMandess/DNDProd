# 05 — Функционал вкладки «Мастер»

Экран входа: две вкладки — **Игрок** / **Мастер**. Этот документ описывает роль Мастера.

## 1. Вкладки мастера

- **Свои приключения** — список сохранённых приключений + создание нового.
- **Архивы персонажей** — снимки персонажей игроков, подключавшихся к комнатам, и созданные мастером NPC; заметки мастера.
- **Справочники** — те же, что у игрока: заклинания, бестиарий, предметы, черты, предыстории (см. `04-player-app.md`, раздел 4).

## 2. Приключение (Adventure)

Контейнер подготовки. Поля:

- **Карты** — один или несколько игровых полей (изображение + сетка). Каждая карта: фон, размер клетки, стартовый туман войны.
- **Токены врагов** — расстановка монстров из `_bestiary_index.json` (полная карточка — из шарда `bestiary_NN.json`) с трекерами хитов (видны только мастеру). Хиты и размер берутся из каталога; размер в клетках: Крошечный/Маленький/Средний = 1, Большой = 2, Огромный = 3, Громадный = 4.
- **Заметки по лору** — текстовые страницы: NPC, фракции, сюжетные ветки.
- **ПМ (приватные заметки)** — видны только мастеру, в том числе во время игры.
- **Настройки** — правила комнаты: можно ли игрокам двигать пешки, авто-трекер инициативы, видимость бросков.

Реализация (2026-11-19, шаг 5.1): приключения — `Adventure`/`AdventureMap`/`LorePage` (`core/models/adventure.dart`) и `AdventureRepository` (`master/adventures/`). JSON лежит в `Documents/dnd_prod/adventures/<id>.json`, фоны копируются в `adventures/<id>/maps/`. У каждой карты отдельное состояние (пешки, туман, штрихи); редактор позволяет добавить/удалить карту, загрузить фон, настроить сетку, поставить монстра из бестиария или NPC, менять хиты и размер, рисовать и открывать туман, вести страницы лора и ПМ. Кнопка «Запустить комнату с этой карты» передаёт серверу готовый снапшот и байты фона. Сохранение правок после сессии и переключение карт во время игры — 5.2.

Реализация (2026-11-19, шаг 5.2): все карты приключения передаются в комнату как `LobbyMap`; запуск принимает `maps:` и `initialMapKey:`. Обновление фона посреди сессии сохраняется в снапшоте текущей карты. После остановки `MasterLobbyController.lastMapStates` содержит состояния всех карт, а кнопка «Внести правки из комнаты» переносит их в редактор (пешки игроков при переносе отбрасываются).

Реализация (2026-11-19, шаг 4.1): поле комнаты — `BattleField` (`lib/shared/field/`): фон карты, сетка, туман, пешки, панорама/зум. В карточке «Карта» мастер загружает своё изображение через `file_picker` или возвращает стандартный фон `assets/maps/grid_basic.jpg`. Файл не копируется на устройства игроков: сервер мастера отдаёт байты по `http://<адрес>:<порт>/map.png?v=N`, ссылка рассылается в `state.map_id`. До перезапуска комнаты карта живёт в памяти сервера; сохранение в приключении — фаза 5.

Реализация (2026-11-19, шаг 4.2): мастер создаёт пешки (вид, размер 1×1…4×4, стартовые ХП), меняет размер и удаляет выбранную, двигает любую пешку долгим нажатием. На панели инструментов поля — «Кисть» (общие штрихи), «Линейка» (клетки и футы), «Туман» с режимами открыть/закрыть. Подготовка карты и тумана до сессии — фаза 5.

## 3. Подготовка карты (до игры)

- Загрузка фона карты (из `assets/maps/` или импорт пользователя).
- Настройка сетки: размер клетки (по умолчанию 70 px, 5 футов), привязка к изображению.
- **Туман войны**: инструментом закрашиваются скрытые области. Сохраняется в приключении.
- Расстановка токенов: перетаскивание монстров из бестиария; у каждого токена — имя, хиты (трекер), состояния.

## 4. Запуск комнаты

- «Запустить комнату» по приключению → приложение поднимает локальный сервер (см. `06-lobby-network.md`) → показывает адрес и QR-код.
- Мастер выбирает стартовую карту. Игроки подключаются и выбирают своих персонажей.
- Мастер видит список подключённых игроков и может отключать их, менять права.
- Реализация (2026-11-19): экран «Комната» поднимает сервер, показывает адрес и QR, список игроков, переключатель права двигать свои пешки, добавляет пешки с видом/размером/ХП, двигает и удаляет их, рисует, измеряет линейкой и управляет туманом; трекер хитов и чат с бросками (скрытые видны только здесь). Запуск из приключения, мультикарты и сохранение правок сессии — шаг 5.1/5.2 (см. разделы 2 и 5).

## 5. Управление во время игры

- **Полный контроль над картой**: перемещение любых пешек, добавление/удаление токенов, рисование, линейка.
- **Туман войны**: для мастера полупрозрачен; инструменты «открыть область» / «скрыть область»; переключение слоя тумана.
- Реализация (2026-11-19, шаг 5.2): карточка «Карты приключения» в экране комнаты — `ChoiceChip` по `controller.mapChoices`, переключение сохраняет текущий снапшот и рассылает `map_switch` с `map_key`; пешки подключившихся игроков создаются заново, если их нет в целевой карте. Правки можно вернуть в приключение кнопкой «Внести правки из комнаты».

- **Показ картинок**: «вывести на экран игроков» — изображение (арт, портрет NPC, подсказка) открывается у всех поверх поля. Реализация (2026-11-19, шаг 5.2): карточка «Картинка игрокам» — «Показать» через `file_picker` и «Скрыть»; мастер шлёт `image_show`, сервер раздаёт байты по `http://<адрес>:<порт>/image.png?v=N`, `image_hide` убирает изображение. У игрока — полноэкранный оверлей с `InteractiveViewer` (зум/панорама) и кнопкой закрытия.
- **Быстрая подгрузка** (2026-11-19): кнопка «Из справочника» в экране комнаты открывает один поиск по монстрам, предметам и заклинаниям (`master/room/quick_load_sheet.dart`) с фильтром по типу. Монстр добавляется пешкой `TokenKind.monster` — размер берётся через `monsterCellSize()`, хиты из полной карточки шарда (при недоступности — из краткой записи индекса). Предмет и заклинание отправляются в общий чат как «Из справочника: …» с названием и урезанным до 180 символов текстом каталога. Никакие бонусы/характеристики не выдумываются.
- **Трекер хитов**: у мастера видны и редактируются хиты всех токенов, включая персонажей игроков (если включено в настройках).
- **Инициатива**: авто-трекер по броскам; сортировка порядка ходов; можно вручную менять.
- **Чат с игроками**: общий и личные сообщения; видит все броски, включая скрытые (помечены).

## 6. Архивы персонажей

- **NPC мастера**: создаются кнопкой «Добавить NPC» — имя, уровень, класс/роль и заметки. Конструктор не генерирует характеристики и не создаёт пешку на поле; для расстановки NPC всё так же используется редактор приключения.
- **Персонажи игроков**: копии персонажей, которые подключались к комнатам мастера (снимок на момент сессии). Только чтение + заметки мастера.

Реализация (2026-11-19, шаг 5.2 + финальные хвосты фазы 5): снимок персонажа сохраняется в архив автоматически в момент подключения игрока к комнате мастера (`hello` → `character_snapshot` → `ArchiveRepository.addSnapshot`). Запись содержит имя персонажа и игрока, уровень, названия классов (из каталога, с откатом к сырым полям JSON), сам снимок и заметки мастера. Записи NPC создаются через `ArchiveRepository.addNpc()`, в JSON есть поле `origin` (`player` или `npc`; старые файлы без поля считаются снимками игроков). Вкладка «Архивы» показывает список с разворачиванием, редактированием заметок и удалением; файлы лежат в `Documents/dnd_prod/archive/characters/<id>.json`.

## 7. Отличия прав мастера от игрока

| Действие | Игрок | Мастер |
|---|---|---|
| Двигать свою пешку | да (если разрешено) | да |
| Двигать любую пешку | нет | да |
| Туман войны | нет | да |
| Трекер хитов врагов | нет | да |
| Видеть скрытые броски | нет | да |
| Переключать карты | нет | да |
| Выводить картинки игрокам | нет | да |
| Управлять комнатой (кик/права) | нет | да |
