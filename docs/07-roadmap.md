## Принятые допущения

- 2026-11-16: drift/SQLite отложен — на MVP каталоги читаются из JSON-assets через CatalogLoader (быстро, офлайн). БД-слой вернём, когда появятся пользовательские коллекции (персонажи, приключения) большого объёма.
- 2026-11-16: `data/catalogs/*.json` закоммичены в git как источник истины для агентов (2.6 МБ, не бинарники).
- 2026-11-19: линейка на поле считает расстояние по клеткам как `max(|dx|, |dy|)`: диагональ = 1 клетка = 5 футов. Это упрощение для экранной линейки, не замена правил D&D; при нужде добавим вариант 5–10–5 из DMG отдельным пунктом настроек.
- 2026-11-19 (шаг 4.3): в быстром листе не выдумываются бонусы атак/урона и ячейки заклинаний — в `Character` таких полей нет; показывается снаряжение и список известных заклинаний по кругам. КД — базовый (10 + Ловкость, без учёта доспеха). Хиты меняются локально в `Character` через `CharacterRepository.save()` и дублируются в чат; серверный `hp_update` остаётся правом мастера.
- 2026-11-19 (шаг 5.1): приключения хранятся как JSON в `Documents/dnd_prod/adventures/<id>.json`, импортированные фоны копируются в `adventures/<id>/maps/` (не ссылкой на исходный файл). Состояние пешек/тумана/штрихов хранится отдельно для каждой карты; запуск комнаты берёт снапшот стартовой карты и не меняет файл приключения до явного сохранения. Возврат правок сессии в приключение (как и переключение карт) — шаг 5.2.
- 2026-11-19 (шаг 5.2): архив персонажей содержит и снимки игроков, подключавшихся к комнатам мастера, и созданных мастером NPC. Конструктор NPC простой (имя, уровень, класс/роль, заметки) — он не генерирует характеристики и не заменяет добавление NPC пешкой в приключении. Протокол остаётся v1: новые типы `image_hide` и `character_snapshot` и поле `room.map_key` добавлены без подъёма версии — старые клиенты просто игнорируют неизвестные типы. Снимок сохраняется автоматически при `hello` игрока; пешки `TokenKind.player` при переносе правок сессии обратно в приключение отфильтровываются.
- 2026-11-19 (финальные хвосты фазы 5): быстрая подгрузка ищет одновременно по монстрам, предметам и заклинаниям из `data/catalogs/`; монстр становится пешкой с размером/хитами из каталога, предмет и заклинание — коротким сообщением в чат. Никаких выдуманных значений: при недоступности шарда бестиария используется краткая запись индекса.
- 2026-11-19 (фаза 5.5): Android-приложение разрешает cleartext-трафик (`usesCleartextTraffic=true`) — лобби работает по `ws://`, а карта/картинки раздаются мастером по `http://` в локальной сети; для интернет-режима (фаза 6) нужно заменить на HTTPS/WSS и убрать разрешение. Release APK сейчас подписан debug-ключом (`build.gradle.kts`), для публикации нужен собственный keystore (без секретов в репозитории).
- 2026-11-19 (фаза 5.5): навигация переключается на `NavigationRail` при ширине ≥ 840 px; `NavigationBar` остаётся основным форм-фактором телефона. Минимальный hit-area 44×44 задан темой, а не разовыми обёртками, чтобы новые кнопки автоматически соблюдали правило переносимости.
- 2026-11-19 (фаза 5.5): macOS-таргет сгенерирован на Windows; сборка `.app` и проверка сетевых entitlement'ов в песочнице возможны только на Mac с Xcode. В `macos/Runner/*.entitlements` разрешены клиент и сервер сети — оба нужны для роли мастера и игрока.
