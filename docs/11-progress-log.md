Заголовок окна пока «dnd_prod» (из windows/runner), переопределить при полировке.
2. **Прокси (критично):** в системе включён локальный прокси `127.0.0.1:10809`; Dart/Flutter **игнорируют системный прокси Windows**. Без переменных `HTTP_PROXY=http://127.0.0.1:10809` и `HTTPS_PROXY=http://127.0.0.1:10809` провайдер шейпит трафик до pub.dev до ~0.5 КБ/с и `pub get` зависает. Всегда добавлять `NO_PROXY=localhost,127.0.0.1,::1`, иначе `flutter test` падает (test-listener ходит на 127.0.0.1). Переменные в систему пока не прописаны — задаются вручную в каждой сессии (решение пользователя).
3. Системные иконки Material — временно, пока не сгенерирован набор из `08-assets.md`. Ассеты подключены в pubspec (`assets/2d/ui/`, `assets/maps/`), папки содержат только `.gitkeep`.
4. Каталоги `data/catalogs/` (2.6 МБ JSON) **закоммичены в git** — это единственный источник истины для агентов; правило «не коммитить большие сгенерированные данные» трактуем как «большие бинарники». Пересбор всё равно через `tools/build_catalogs.py`.
5. `pubspec.lock` в `.gitignore` (приложение, не пакет).
6. drift заявлен в зависимостях, но БД-слой не писан — решено отложить (см. раздел 3): на старте хватит JSON через FileStore.
7. Ассеты пользователя (png/jpg в `assets/`) не коммитим — `.gitignore` держит только `.gitkeep`.
