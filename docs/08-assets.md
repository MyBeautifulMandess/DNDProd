## Чего здесь НЕТ и почему

- **Токены монстров/персонажей** — добавляются пользователем из справочника при первом запуске (генерация по ходу игры, см. `09-ai-integration.md`).
- **Дополнительные локации** (подземелье, замок и т.п.) — мастер импортирует свои карты.
- **Шрифты** — используем системные с поддержкой кириллицы (например, «Segoe UI» на Windows, «Roboto» на Android), отдельная генерация не нужна.
- **Сплэш-скрин, баннеры, ачивки** — не требуются для MVP.

## Критерии приёмки

- Нет текста, водяных знаков, рамок.
- Единый стиль и палитра во всех файлах.
- Размеры строго по спецификации.
