# 03 — Создание и прокачка персонажа

Источник данных: `data/catalogs/classes_5e14.json`, `_classes_core.json`, `races_5e14.json`, `_races_detail.json` (бонусы/скорость/размер/черты/подвиды), `backgrounds_full.json`, `spells_5e14.json`, `_classes_equipment.json` (стартовые наборы). Все названия и уровни умений сверены с dnd.su.

## 1. Пайплайн создания (пошагово)

1. **Раса/происхождение** — выбор из `races_5e14.json` (80 рас). Черты рас — на странице расы по ссылке из каталога (якоря подвидов — в `_races_subspecies.json`). Раса даёт бонусы характеристик, размер, скорость, чувства, навыки/черты.
2. **Класс** — 13 классов (см. ниже). Определяет кость хитов, владения, спасброски, стартовые умения.
3. **Характеристики** — point buy (27 очков, 8–15 до расовых) или стандартный массив [15,14,13,12,10,8]. Расовые бонусы прибавляются.
4. **Предыстория** — из `backgrounds_full.json` (89 штук): даёт 2 навыка, инструменты/языки, снаряжение, умение предыстории.
5. **Снаряжение** — по классу + предыстории (списки в `_classes_core.json` и `backgrounds_full.json`).
6. **Заклинания** (для заклинателей) — известные/подготовленные из `spells_5e14.json` по классу и уровню.
7. **Имя, внешность, аватар, личные заметки** — пользовательские поля.

## 3. Прокачка (level-up)

- На каждом уровне: хиты по кости класса, новые умения из таблицы прогрессии (`classes_5e14.json`), на 4/8/12/16/19 — увеличение характеристик (или черта).
- Заклинатели: новые известные/подготовленные заклинания и ячейки по таблице класса.
- Мультиклассирование — опционально, правила на dnd.su (`/articles/mechanics/449-multiclassing/`); на старте можно не реализовывать, но модель данных должна допускать несколько классов.

## 4. Валидация

- Характеристики: 1–20 (без магических предметов), максимум 15 на старте до расовых.
- Навыки: только из списка класса + предыстории; владение не суммируется.
- Заклинания: только из списка класса, уровень заклинания ≤ доступным ячейкам.

## 5. Экспорт/импорт

- Формат: JSON (`Character` схема). Экспорт — файл или share-ссылка.
- Версия схемы в каждом файле, чтобы мигрировать старых персонажей.
