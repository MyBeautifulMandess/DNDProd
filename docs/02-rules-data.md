# 02 — Правила D&D 5e как данные

Все формулы — официальные (Player's Handbook 2014, dnd.su). ИИ-агент обязан использовать эти формулы, а не приближения. Полный контент — в `data/catalogs/`.

## 1. Характеристики

Шесть характеристик: **Сила (СИЛ), Ловкость (ЛОВ), Телосложение (ТЕЛ), Интеллект (ИНТ), Мудрость (МДР), Харизма (ХАР)**.

- **Модификатор** = `floor((значение − 10) / 2)`. Диапазон 1–20 → модификатор от −5 до +5.
- Базовое значение при создании: 8 + распределение очков (point buy 27 очков) или броски; максимум на старте обычно 15 (без расовых бонусов).
- Расовые бонусы добавляются к базовым значениям.

## 2. Производные величины

- **Класс Доспеха (КД)** = 10 + модификатор ЛОВ + бонус доспеха + щит. Без доспехов: 10 + ЛОВ (умения «Защита без доспехов» дают другую формулу — см. класс).
- **Хиты (HP)** на 1 уровне = максимум кости хитов класса + модификатор ТЕЛ. На следующих уровнях = бросок кости хитов (или фикс. среднее, округление вверх) + модификатор ТЕЛ.
- **Бонус мастерства (БМ)** = `2 + floor((уровень − 1) / 4)` → 1–4:+2, 5–8:+3, 9–12:+4, 13–16:+5, 17–20:+6.
- **Пассивное Восприятие** = 10 + МДР (Восприятие) + бонусы.
- **Инициатива** = бросок к20 + модификатор ЛОВ.

## 3. Броски

- **d20-тест**: бросок d20 + модификатор (+ БМ, если владеешь). Преимущество/помеха — два кубика, берётся больший/меньший.
- **Сложность (Сл)**: лёгкая 10, средняя 15, сложная 20, очень сложная 25, почти невозможная 30.
- **Спасбросок** = d20 + модификатор характеристики (+ БМ, если владеешь спасброском).
- **Бросок атаки** = d20 + модификатор характеристики + БМ + бонусы оружия.
- **Урон**: кости урона класса оружия/заклинания + модификатор (СИЛ для рукопашного, ЛОВ для дальнобойного/фехтовального, ХАР/ИНТ/МДР для заклинаний по классу).

## 4. Навыки (18 штук)

Акробатика (ЛОВ), Атлетика (СИЛ), Восприятие (МДР), Выполнение (ХАР), Выживание (МДР), Запугивание (ХАР), История (ИНТ), Ловкость рук (ЛОВ), Магия (ИНТ), Медицина (МДР), Обман (ХАР), Природа (ИНТ), Проницательность (МДР), Расследование (ИНТ), Религия (ИНТ), Скрытность (ЛОВ), Убеждение (ХАР), Уход за животными (МДР).

## 5. Класс Доспеха доспехов

- **Лёгкие**: КД = 11–12 + ЛОВ (кожаный 11, проклёпанный кожаный 12).
- **Средние**: КД = 12–15 + ЛОВ (макс +2) — шкурный 12, кольчуга 14, чешуйчатый 14+? (точные значения в `data/catalogs/items_5e14.json`).
- **Тяжёлые**: фиксированный КД (листовой 18, латный 18 с помехой Скрытности).
- **Щит**: +2 к КД.

## 6. Ячейки заклинаний

Полная таблица по классам и уровням — в `data/catalogs/classes_5e14.json`, колонки «Ячейки заклинаний на уровень заклинаний».

- Полноценные заклинатели (бард, жрец, друид, волшебник): уровень заклинателя = уровень класса.
- Полукастеры (паладин, следопыт, изобретатель TCE): уровень заклинателя = уровень класса (или половина для мультикласса — правило в PHB).
- Колдун: ячейки всегда максимального уровня, восстанавливаются на коротком отдыхе; число ячеек по таблице класса.

## 7. Опасность (CR) и опыт

Соответствие CR опыту — в `bestiary_5e14.json`, поле `xp`. Ориентиры для баланса встречи — на dnd.su: `https://dnd.su/encounter_difficulty/`.

## 8. Проверка данных

Агент, реализующий расчёты, обязан покрыть формулы тестами на краях: значение 1 (модификатор −5), 20 (+5), 30 (+10), БМ на уровнях 1/5/9/13/17.
