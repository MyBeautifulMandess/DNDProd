# 04 — Функционал вкладки «Игрок»

Экран входа: две вкладки — **Игрок** / **Мастер**. Этот документ описывает роль Игрока.

## 1. Мои персонажи

- Список сохранённых персонажей (несколько). Карточка: аватар, имя, раса, класс, уровень.
- Действия: создать, открыть, дублировать, удалить, **экспорт/импорт** (JSON, см. `03-character-builder.md`).
- Персонаж хранится локально, работает без сети.

## 2. Создание и прокачка

Пошаговый билдер по `03-character-builder.md`. Прокачка: при достижении нового уровня мастером (или вручную) открывается мастер прокачки — новые умения из таблицы класса, увеличение характеристик, новые заклинания. Все опции строго из `data/catalogs/`.

## 3. Лист персонажа в игре (вкладка в лобби)

Быстрый доступ во время сессии:

- **Хиты**: текущие/максимум, временные хиты; кнопки ±1, ±5, кубик хитов.
- **Статы**: шесть характеристик с модификаторами; спасброски; инициатива; КД; скорость; пассивное Восприятие.
- **Атаки**: оружие персонажа — название, бонус попадания, урон (формулы из `02-rules-data.md`).
- **Заклинания**: карточки заклинаний с фильтром по уровню; ячейки по кругам; кнопка «сотворить» (списывает ячейку, отправляет в лог).
- **Навыки**: список с владением; тап — бросок d20 прямо в чат лобби.
- **Инвентарь/особенности**: предметы и классовые умения (описания по ссылке из каталога).

Реализация (2026-11-19, шаг 4.3): быстрый лист открывается кнопкой «Лист персонажа» на экране подключения и в активной сессии (`lib/player/sheet/character_sheet_panel.dart`, `showModalBottomSheet`). В листе есть шапка с КД/инициативой/скоростью/пассивным Восприятием/бонусом мастерства, хиты с ±1/±5 и костью хитов класса, характеристики, спасброски и навыки (тап → `1к20+бонус` в общий чат),заклинания по кругам с кнопкой «Наложить» (текст в чат), снаряжение и черты/умения из каталогов. Формулы бросков строит хелпер `core/rules/roll_formula.dart` — они совместимы с протоколом лобби.

Ограничения 4.3: бонусы атак и урона в модели `Character` не хранятся — раздел «Снаряжение» показывает только строки снаряжения, выдуманные числа не добавляются; ячейки заклинаний не учитываются (есть только список известных заклинаний по кругам); КД пока базовый (10 + Ловкость, без доспеха); изменение ХП локально для персонажа игрока (`repository.save`) и дублируется в чат, серверное `hp_update` остаётся за мастером. Броски/сообщения из листа до подключения к комнате недоступны.

## 4. Справочники (изучение)

Общие для игрока и мастера, данные из `data/catalogs/`:

- **Заклинания** (524): сортировка/фильтры по уровню, школе, классу, концентрации, ритуалу, урону. Поиск по названию (ru/en).
- **Бестиарий** (2673): фильтры по CR, размеру, типу, среде обитания, источнику.
- **Предметы** (901): фильтры по редкости, типу, настройке.
- **Черты** (105), **Предыстории** (89) — справочно.
- Каждая карточка содержит ссылку «Источник» на страницу dnd.su для полного текста.

Реализация (2026-11-18, шаг 2.1): общий слой `lib/shared/catalog_ui/` — хаб разделов, универсальный экран списка с поиском и чипами фильтров, карточка с открытием ссылки во внешнем браузере (`url_launcher`). Справочники доступны и игроку, и мастеру. Фильтры нормализуют свободный текст каталогов («Средняя?» → «Средний»). Полные тексты есть только у заклинаний и предысторий; у существ, предметов и черт карточка показывает поля каталога.

## 5. Подключение к лобби мастера

- Мастер запускает комнату → получает локальный адрес (IP:порт) и QR-код.
- Игрок: «Подключиться» → ввод адреса или скан QR → выбор персонажа → вход в комнату.
- На старте — только локальная сеть (Wi-Fi/LAN). Интернет-соединение — позднее через сервер мастера (см. `06-lobby-network.md`).
- Реализация (2026-11-19): игрок вводит `IP:порт` (QR генерируется на экране мастера, сканер камеры не добавлен), выбирает сохранённого персонажа — имя, id и хиты уходят в `hello`. После `welcome` открывается базовая сетка с пешками, чат и формула броска с переключателем «Скрыто»; скрытый бросок виден только мастеру.

## 6. Игровое поле (в лобби)

- **Общий вид на карту**: сетка клеток, пешки всех участников, аватарки персонажей в углу/панели.
- **Перемещение**: игрок перемещает только свою пешку (drag & drop по клеткам), если мастер разрешил.
- **Рисование по полю**: свободные линии/маркеры, видны всем (цвет по игроку).
- **Линейка**: измерение расстояний по сетке (в клетках и футах; 1 клетка = 5 футов).
- **Туман войны**: игрок видит только то, что открыл мастер; своё поле зрения не считаем (упрощение на старте).

Реализация (2026-11-19, шаг 4.1): в lobby вместо простой сетки — `BattleField` (`lib/shared/field/`): фон из `assets/maps/grid_basic.jpg`, сетка и туман через `CustomPainter`, панорама/зум через `InteractiveViewer` и кнопки 44×44. Игрок двигает свою пешку долгим нажатием и перетаскиванием или выбором пешки и тапом по клетке; кисть и линейка доступны всем участникам, туман — только мастеру (шаг 4.2). Свою карту мастер загружает файлом, сервер раздаёт её игрокам по HTTP (см. `06-lobby-network.md`).

## 7. Общение

- **Общий чат** комнаты: текст, результаты бросков (кубики), системные сообщения.
- **Личные сообщения**: с мастером и между игроками.
- **Броски кубиков**: любые формулы (2к6+3 и т.п.); **скрытый бросок** — виден только мастеру (переключатель при броске).

## 8. Аватарки

- Аватар персонажа виден в списке участников, на его пешке и в чате.
- Размер аватара: 128×128 px, WebP/PNG (см. `08-assets.md`).

## 9. Ограничения роли Игрок

- Не видит статблоки монстров (только имя/картинку, если мастер показал).
- Не видит трекер хитов врагов, приватные заметки мастера, скрытые области карты.
- Не может двигать чужие пешки (кроме случаев, когда мастер выдал право).
